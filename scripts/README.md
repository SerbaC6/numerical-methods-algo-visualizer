# `scripts`

Scripturi de întreținere, rulate manual. Nu fac parte din build.

| Script                 | Ce face                                                                  |
| ---------------------- | ------------------------------------------------------------------------ |
| `descarca-fonturi.py`  | descarcă subseturile latin + latin-ext ale fonturilor în `public/fonts`  |
| `verifica-contrast.py` | verifică raportul de contrast WCAG pe perechile text/fundal, ambele teme |

Cer doar Python 3, fără dependențe externe.
