# Animații sursă

Animațiile web gata făcute din care s-au portat clipurile din secțiunea „Vizual". **Nu fac parte
din site**: nu sunt importate de nicăieri, nu intră în build și nu se deschid din interfață. Se
păstrează exact cum au venit — fiecare e un bundle generat (React UMD + Babel + fonturi, într-o
singură linie de peste 1 MB), de aceea folderul e în `.prettierignore`.

Rămân în repo ca material de referință: dacă un clip portat trebuie corectat, aici se vede
originalul care a fost portat, cu cifrele și cu succesiunea lui de momente.
